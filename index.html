Inaccessible Sites
Pattern A — abbv-tab-* Deep-Link URLs
AbbVie's tab component auto-generates anchor URLs for each tab. These appear in XML sitemaps but return 404 on direct navigation. Affects 12 sites, ~120 phantom URLs.
abbv-tab-XXXXXXXXXX-0, abbv-tab-XXXXXXXXXX-1…
Pattern B — URL-Doubled Paths
Sites hcp.xengelstent.com and savewithays.com have sitemap entries where the hostname is repeated in the path (e.g. site.com/site.com/page-path). All return 404.
hcp.xengelstent.com/hcp.xengelstent.com/…
Pattern C — AEM Fragment Pages
durystahcp.com has /site-modols/* paths in the sitemap. These are AEM Sling component fragment pages, not real content pages authored for end-users.
/site-modols/jcr:content/…
